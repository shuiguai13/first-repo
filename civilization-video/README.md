## 关于“未来三十年”

未来部分是基于当前趋势、科研进展和公开规划的展望，片中用“展望”“有望”“可能”标出，不是确定的预言。用到的预测数字：

- 世界人口 2050 年约 97 亿；届时约六分之一的人超过 65 岁（联合国《世界人口展望》中位预测）
- 全球人均预期寿命 2054 年约 77 岁（联合国《世界人口展望 2024》）
- 2030 年可再生能源约占全球发电近一半，2023 年约 30%（国际能源署 IEA）
- 碳中和目标年：欧盟、英国、日本 2050，中国 2060，印度 2070

## 主要史实与数据

- 已知最早的石器约 330 万年前（肯尼亚 Lomekwi 3）；用火证据约 100 万年前；智人约 30 万年前出现于非洲
- 约 1820 年 → 今天：人均预期寿命约 29 岁 → 73 岁；极端贫困比例约 76% → 约 10%；识字率约 12% → 约 87%；五岁前儿童死亡率约 43%（1800 年）→ 3.7%（Our World in Data、联合国、世界银行）
- 芯片晶体管数：Intel 4004（1971）2300 个 → NVIDIA Blackwell B200（2024）2080 亿个
- 世界人口曲线：HYDE / 联合国估计；1800 年以前的寿命为估算值（图中用虚线表示）

## 制作方式

视频的每个部分都由本目录里的代码生成，可以完整复现：

1. **解说词** `script/script.json`：显示文本（字幕）和朗读文本分开写，数字按中文读法朗读。
2. **配音** `tools/tts.py`：微软 Azure 神经语音「云健」（经 edge-tts 调用，需要能访问 `speech.platform.bing.com`）。每句话整句合成，语调自然连贯；用服务返回的词级时间戳对齐字幕和画面节拍。再用 SenseVoice 语音识别回听校验，全片平均字错率约 1.4%（剩余差异基本是同音字）。无网络时可用 `--engine kokoro` 改为离线合成（Kokoro v1.1-zh，音质较差）。
3. **画面** `render/`：HTML Canvas 动画引擎，每一帧都是时间的纯函数；地图来自 Natural Earth（world-atlas），图标来自 Lucide。用无头 Chromium 并行渲染成 JPEG 帧。
4. **配乐与音效** `tools/music.py`：按章节情绪程序化生成和弦铺底、琶音、打击乐和转场音效，有旁白时自动压低音乐。
5. **合成** `tools/encode.sh`：ffmpeg 输出 H.264/AAC，响度标准化到 −16 LUFS。

一键重建（需要 Node 18+、Python 3.10+、ffmpeg 和 Playwright Chromium；首次会下载约 600 MB 的字体和模型）：

```bash
cd civilization-video
./build.sh            # 或 WORKERS=8 ./build.sh
```

只预览某一时刻的画面：`node render/preview.mjs /tmp/preview fire:12.5 info:30`（`场景:秒` 或全片秒数）。
